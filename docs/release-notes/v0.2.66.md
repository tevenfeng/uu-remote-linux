修复版：虚拟手柄摇杆 Y 轴方向。/ Hotfix: virtual-gamepad stick Y direction.

### 修复 / Fixed
- **手柄两摇杆上下方向反转（v0.2.65 回归）**：`gpd_update` 的 `left_thumb_y`/`right_thumb_y` 是 XInput 约定（上=正值），而 Linux 内核 evdev 手柄读取约定是上=负值（`xpad` 驱动对真实 Xbox 硬件同样做 Y 取反）。v0.2.65 按直传注入导致游戏内上下颠倒（左右正常）。现在 ABS_Y/ABS_RY 翻转注入，`-32768` 饱和为 `+32767`；X 轴、扳机、十字键两种约定一致不受影响。触发器范围、按键映射与震动链路无变化。/ `gpd_update` thumb Y values follow the XInput convention (up=positive), but kernel evdev gamepads read up=negative (the xpad driver flips Y for real Xbox hardware). v0.2.65 passed them through verbatim, so both sticks moved up/down inverted in games (left/right was fine). ABS_Y/ABS_RY now inject sign-flipped, saturating -32768 to +32767; X, triggers and the dpad match both conventions and are unchanged.

### 验证范围 / Validation
新增符号翻转与饱和单元测试（含 `-32768 → +32767` 单帧满行程仍发事件），既有解码/差分/清扫测试同步更新；维护者已用官方客户端实机复现 v0.2.65 症状。/ New unit tests pin the flip and saturation (including a one-frame -32768 → +32767 slam still emitting); decode/diff/sweep tests updated. The v0.2.65 symptom was reproduced on real hardware by the owner.
