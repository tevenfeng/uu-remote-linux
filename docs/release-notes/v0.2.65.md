功能版：被控端支持虚拟手柄输入与震动回传。/ Feature release: the host accepts virtual-gamepad input and forwards rumble.

### 新增 / Added
- **被控端虚拟手柄（实验性）**：官方手机端「虚拟手柄」与 SDL 控制端转发的实体手柄（`UU_VIEWER_NATIVE_GAMEPAD=1`）发送的 `gpd_*` 消息，现在被解码并注入为内核级 Xbox 360 手柄（uinput，udev 显示 "Microsoft X-Box 360 pad"，SDL2/Steam 按内置 xpad 映射识别）。最多 4 个手柄；X11 与 Wayland 桌面同样可用——键鼠后端不变，手柄独立走内核，不受 `UU_INPUT_BACKEND` 影响。协议逐字段照抄官方 Windows 4.45 逆向证据（RVA 0x5dde60/0x5ddb30/0x5dfba0，见 docs/deckpad-native-gamepad.md）。断连清扫兜底：被控端异常退出的控制端来不及发 `gpd_disconnect` 时由既有的输入复位逻辑释放按键。/ The `gpd_*` messages sent by the official mobile virtual gamepad and by physical controllers forwarded from the SDL viewer now decode and inject as kernel Xbox 360 pads through uinput (udev shows "Microsoft X-Box 360 pad"; SDL2/Steam recognize the built-in xpad mapping). Up to 4 pads; works on X11 sessions too — the keyboard/mouse backend is unchanged, gamepads go through the kernel independently of `UU_INPUT_BACKEND`. Message shapes are copied field-for-field from the official Windows 4.45 static evidence. A stuck-button backstop releases pads when a viewer exits without `gpd_disconnect`.
- **震动回传**：游戏的双马达震动以官方 `gpd_vibration` JSON 回传控制端（raw bytes，无 protobuf envelope），FF_RUMBLE 强/弱马达对应 XInput 左/右马达。`UU_GAMEPAD=0` 整体关闭，`UU_GAMEPAD_RUMBLE=0` 只关震动（虚拟手柄对游戏显示为无震动能力）。/ In-game two-motor rumble returns to the client as the official `gpd_vibration` JSON (raw bytes, no protobuf envelope); ff_rumble strong/weak map to the XInput left/right motors. `UU_GAMEPAD=0` disables the feature entirely, `UU_GAMEPAD_RUMBLE=0` disables rumble only.
- 需要 /dev/uinput 权限（与键鼠 uinput 相同的 uaccess 规则，README 第 5 步）；`doctor` 现在报告 gamepad 后端状态。/ Requires /dev/uinput access (the same uaccess rule as the uinput keyboard/mouse, README step 5); `doctor` now reports the gamepad backend state.
- SDL 控制端的原生手柄实验从此也支持本项目的 Linux 被控端（原文案与 gate 不一致，gate 本就只拒绝 Mac 主机）。/ The viewer's native gamepad experiment now also covers this project's Linux host (the old copy said Windows-only; the gate actually only refuses Mac hosts).

### 验证范围 / Validation
单元与集成测试覆盖解码、位/轴映射、差分注入、断连清扫、FF uapi 布局断言（ff_effect 48 / upload 104 / erase 12 字节与内核事件码）及 raw JSON 回传出站；维护方尚未实机验收官方手机端虚拟手柄与带震动的游戏。/ Unit and integration tests cover decode, bit/axis mapping, transition diffing, release sweep, FF uapi layout assertions (ff_effect 48 / upload 104 / erase 12 bytes and kernel event codes) and the raw JSON forwarder; the official mobile virtual gamepad and a rumbling game are not yet field-accepted by the maintainer.
